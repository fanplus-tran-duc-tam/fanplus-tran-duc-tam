# 💫 About Me:

### Hi there 👋, I'm Trần Đức Tâm (Sunny292)
**ソフトウェアエンジニアリングリーダー | バックエンド＆モバイル開発者 | DevSecOps 愛好家**

2012年にキャリアをスタートし、ソフトウェア開発の分野で10年以上の経験があります。そのうち8年間は日本市場で直接働き、開発者、プリセールス、テクニカルリーダー（要件定義・基本設計・詳細設計を専門とする）として様々な役割を担ってきました。最も記憶に残る原点は、卒業制作として**TopCV**を構築したことです。それ以来、拡張性の高いシステムの設計と運用に常に情熱を注いでいます。

Flutter/Android開発に精通し、Stack Overflowで4,000点以上の貢献実績を持つソリューションアーキテクトです。モバイル開発の深い知見に加え、現在はAWSを用いたバックエンド設計やDevSecOpsの導入によるシステム全体の最適化を推進しています。

現在は、アーティストやファン向けのウェブサイト作成プラットフォーム「KIT」システムを開発・運用する12名のエンジニアチームを率いています。
